# Zombie-Escape

A C++ maze escape game using BFS pathfinding.

## SFML Setup

This project is configured for the MinGW toolchain and SFML 3.1.0.

### SFML Configuration

- Include directory: `C:/SFML/SFML-3.1.0/include`
- Library directory: `C:/SFML/SFML-3.1.0/lib`
- Libraries used: `sfml-graphics`, `sfml-window`, `sfml-system`

The VS Code build tasks copy the required SFML DLLs next to the generated executable before running it.
