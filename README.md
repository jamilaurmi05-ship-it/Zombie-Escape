
# ZOMBIE ESCAPE

## Project Description
Zombie Escape is a 2D survival game
developed using C++ and SFML.

The player must escape from zombies,
avoid walls and reach the exit point.

## Objectives
- Survive from zombies.
- Avoid obstacles.
- Reach the exit.
- Achieve a high score.

## Technologies Used
- C++
- SFML
- Visual Studio Code
- GitHub

## Algorithms and Data Structures
- Breadth First Search (BFS)
- Queue
- 2D Array
- Visited Array
- Parent Array
- Vector

## Game Controls
- W = Move Up
- S = Move Down
- A = Move Left
- D = Move Right
- Left Shift = Speed Boost
- M = Return to Menu

## Main Features
- Player Movement
- Zombie AI
- BFS Pathfinding
- Wall Collision
- Health System
- Score System
- Survival Timer
- Win and Game Over System
